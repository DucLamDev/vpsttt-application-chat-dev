# Mobile UI Reference Cho Agent

Đây là bản nhắc nhanh cho agent. Nguồn chính nằm ở:

- `docs/planning/mobile-flutter-roadmap.md`
- `docs/design/mobile/references/mobile-ui-reference.md`
- `docs/design/mobile/references/webtui-mobile-zalo-reference.png`

Khi làm UI Flutter, bắt buộc mở ảnh reference. Nếu ảnh chưa có trong workspace, không tự tưởng tượng lại UI; yêu cầu đặt ảnh gốc vào đúng path trước khi triển khai màn hình.

Tinh thần thiết kế:

- Zalo-like, sáng, chuyên nghiệp, nhiều thông tin.
- Bottom navigation rõ: Tin nhắn, Danh bạ, Khám phá/Kênh, Thêm/Cài đặt.
- Tích hợp `Kênh & Bot` như một phần quan trọng của app.
- Dùng segmented tab, list item dày, avatar/icon mềm, badge chưa đọc nhỏ.
- Không dùng landing page, không dùng hero gradient, không dùng UI card phình to kiểu marketing.
